# 6T SRAM Cell – Schematic, Simulation & Layout

This repository contains the **schematic design**, **transient simulations**, **butterfly curve analysis**, and **layout implementation** of a standard **6‑Transistor (6T) SRAM cell**.

---

## 1. Schematic design

The 6T SRAM cell consists of:

- **2 cross‑coupled inverters** (storage nodes Q and QB)  
- **2 NMOS access transistors** (controlled by WL)  
- **Bit‑lines BL and BLB** for read/write operations  

The schematic is designed using standard CMOS design rules.

---

## 2. Output plots

### 2.1 Transient response

**Objective:** Observe the dynamic behavior of the SRAM cell during different operations.

Includes plots of:

- Q  
- QB  
- WL  
- BL / BLB  

**Operations captured:**

- Write ‘0’  
- Write ‘1’  
- Hold  
- Read  

---

### 2.2 Butterfly plot (QB vs Q) with SNM

**Objective:** Evaluate the **Static Noise Margin (SNM)** of the 6T SRAM cell.

The butterfly curve is generated by plotting **QB vs Q** from the DC transfer characteristics of the cross‑coupled inverters.

Includes:

- Butterfly plot (QB vs Q)  
- **Static Noise Margin line (SNM)** using maximum square method  

This verifies the stability of the cell in **read** and **hold** modes.

---

## 3. Layout design

The **6T SRAM layout** is implemented following standard CMOS layout rules.

Key aspects:

- **DRC‑clean** layout  
- Minimum **width** and **spacing** rules respected  
- **Shared diffusion** for inverter transistors where possible  
- Proper **poly gate alignment** for matched devices  
- **Metal routing** for:
  - Wordline (WL)  
  - Bitlines (BL, BLB)  
  - Storage nodes (Q, QB)  
- **Well taps** and **substrate contacts** for noise and latch‑up prevention
